🎓 Student Application & Recommendation Platform

📌 Overview

The Student Application Platform is a full-stack system designed to help students apply to higher education institutions while receiving intelligent course and institution recommendations based on their academic performance.

This project aims to simplify the application process and provide guidance to students who may be unsure about which courses or institutions suit their results.

---

🚀 Features

👤 Student Side

- Create and manage student profiles
- Enter academic results (subjects & marks)
- Get course recommendations
- Get institution suggestions
- Submit applications directly through the platform
- Track application status (Pending / Approved / Rejected)

---

🛠️ Admin Side

- Secure admin login
- View all student applications
- Approve or reject applications
- Real-time status updates

---

🧠 Smart Recommendation System (In Progress)

- APS (Admission Point Score) calculation
- Course matching based on subject performance
- Institution eligibility filtering
- Dynamic recommendations (based on marks)
